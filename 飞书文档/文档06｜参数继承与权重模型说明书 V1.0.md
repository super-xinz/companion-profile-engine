# 文档目的

本文档用于定义：

> 九型人格 AI陪伴聊天策略模型中，不同人格参数来源如何继承、融合以及影响最终互动策略生成。
> 
> 

本文档解决的问题：

1. 一个用户的人格组合如何被解析； 

2. 主型、侧翼、本能叠层分别贡献什么参数； 

3. 不同参数如何组合生成最终互动画像； 

4. AI互动策略如何基于融合结果生成。 

---

# 人格组合输入规范

## 2\.1 输入格式

九型人格组合统一采用：

```Plain Text
第一副型/第二副型｜主型侧翼
```

示例：

```Plain Text
SX/SO｜7w6
```

# 参数继承总体原则

## 3\.1 基本原则

九型人格互动模型不是简单标签叠加。

采用：

> 主型提供底层人格动力，侧翼提供表达修正，本能叠层提供注意力和资源方向，状态参数提供动态调整。
> 
> 

---

整体结构：

```Plain Text
人格组合

=

主型 Core Type

+

侧翼 Wing

+

本能叠层 Instinct Stack

+

状态 State
```

---

# 参数来源映射规则

## 4\.1 主型参数继承规则

### 来源：

Core Type

### 权重：

最高。

### 主要负责：

- 核心驱动力； 

- 深层恐惧； 

- 核心需求； 

- 基础防御机制； 

- 安全/压力状态。 

---

示例：

7号：

主型提供：

```Plain Text
核心驱动力：
探索可能性

深层恐惧：
失去自由和选择

核心需求：
保持开放和体验
```

---

# 4\.2 侧翼参数继承规则

### 来源：

Wing

### 主要作用：

> 修正主型表达方式。
> 
> 

---

影响：

- 行为风格； 

- 信息处理方式； 

- 决策方式； 

- 情绪表达方式。 

---

示例：

7号：

基础：

```Plain Text
探索可能性
```

---

7w6：

增加：

```Plain Text
安全意识
关系意识
风险评估
```

---

7w8：

增加：

```Plain Text
力量感
行动性
突破性
```

---

# 4\.3 第一副型参数继承规则

### 来源：

Primary Instinct

### 主要作用：

> 决定人格资源优先投入方向。
> 
> 

---

影响：

- 注意力焦点； 

- 行动优先级； 

- 关系关注方向。 

---

三类本能：

## SP（自保）

关注：

- 安全 

- 稳定 

- 资源 

- 身体和现实基础 

---

## SX（一对一）

关注：

- 强连接 

- 深度体验 

- 情感强度 

- 特殊关系 

---

## SO（社群）

关注：

- 群体位置 

- 价值贡献 

- 社会连接 

- 共同目标 

---

# 4\.4 第二副型参数继承规则

### 来源：

Secondary Instinct

### 主要作用：

> 提供辅助策略。
> 
> 

---

特点：

第二副型不是主要驱动力。

但会影响：

- 行为补充方式； 

- 社交策略； 

- 资源分配方式。 

---

例如：

```Plain Text
SX/SO
```

表示：

第一关注：

深度连接。

辅助：

群体影响。

---

而：

```Plain Text
SO/SX
```

表示：

第一关注：

群体价值。

辅助：

深度关系。

---

两者互动表现不同。

---

# 六层参数生成规则

---

# Layer 1：Identity Layer

生成：

```Plain Text
identity:

  core_type:
  wing:
  instinct_stack:
```

来源：

100%来自输入结构。

---

# Layer 2：Motivation Layer

生成：

```Plain Text
motivation:

  core_drive:

  core_fear:

  core_need:
```

主要来源：

```Plain Text
主型
```

权重：

主型决定。

侧翼、本能：

辅助修正。

---

公式：

```Plain Text
Motivation

=

Core Type

+ Wing Adjustment

+ Instinct Adjustment
```

---

# Layer 3：Attention Layer

生成：

```Plain Text
attention:

  focus:

  information_processing:

  decision_style:
```

来源：

```Plain Text
主型

+

第一副型

+

侧翼
```

---

权重逻辑：

```Plain Text
主型：
决定关注领域

第一副型：
决定关注优先级

侧翼：
决定处理方式
```

---

# Layer 4：Expression Layer

生成：

```Plain Text
expression:

  persona:

  emotion_style:

  relationship_style:
```

来源：

```Plain Text
侧翼

+

本能叠层

+

主型
```

---

权重：

侧翼影响表达风格最大。

---

# Layer 5：State Layer

生成：

```Plain Text
state:

  secure_state:

  stress_state:

  defense:
```

主要来源：

主型。

---

原因：

安全状态和压力状态，本质来源于：

- 核心需求满足； 

- 核心恐惧激活。 

---

# Layer 6：Interaction Strategy

最终输出：

```Plain Text
interaction_strategy:

 communication:

 motivation:

 conflict:

 companionship:
```

来源：

所有人格参数综合。

# 权重模型

## 6\.1 静态人格权重

V1\.0采用：

```Plain Text
主型                 45%

第一副型             20%

第二副型             10%

侧翼                 15%
```

---

说明：

### 主型45%

决定：

人格底层动力。

---

### 第一副型20%

决定：

注意力资源方向。

---

### 第二副型10%

决定：

辅助行为策略。

---

### 侧翼15%

决定：

人格表达修正。

---

# 6\.2 动态状态权重

当前状态：

10%

---

完整模型：

```Plain Text
最终互动画像

=

+

动态状态修正（10%）
```

# 参数融合规则

## 7\.1 非线性组合原则

人格不是：

```Plain Text
7号 + 6号 + SX + SO
```

简单相加。

---

而是：

```Plain Text
7号核心动力

↓

6号表达修正

↓

SX关系强化

↓

SO社会连接

↓

生成最终互动倾向
```

---

# 7\.2 冲突参数处理规则

当不同参数产生冲突：

优先级：

```Plain Text
核心动机

>

第一副型需求

>

侧翼表达方式

>

第二副型辅助方式
```

---

示例：

SX/SO｜7w6

可能同时存在：

7号：

想探索。

6翼：

想确认安全。

SX：

想获得强连接。

SO：

想融入群体。

---

融合结果：

不是：

“既想自由又想安全”。

而是：

> 在有连接和支持的环境中探索新的可能。
> 
>
