# 文档02｜初始人格信息 → 九型互动参数接口规范 V1\.0

**文档版本：V1\.0**
**文档类型：数据接口设计说明**
**适用对象：产品、算法、研发、数据团队**

---

# 文档目的

本文档用于定义：

> 初始人格分析系统与九型人格 AI陪伴聊天策略模型之间的数据衔接方式。
> 
> 

本文档不负责定义：

- 初始人格分析系统如何生成用户画像； 

- 初始人格分析算法如何实现； 

- 不同人格理论之间的准确性关系。 

本文档仅解决：

> 当外部系统已经生成用户人格信息后，如何转换为九型互动参数模型可使用的数据结构。
> 
> 

---

# 接口定位

在整体系统中，本接口位于：

```Plain Text
初始人格分析系统

↓

【人格信息转换接口层】

↓

九型人格参数模型

↓

AI互动策略生成模块
```

---

# 设计原则

## 3\.1 九型模型作为互动解释层

初始人格系统输出的是：

> 用户人格特征信息。
> 
> 

九型互动模型接收后，将其转换为：

> 用户互动倾向参数。
> 
> 

---

因此：

外部信息：

关注：

- 行为表现； 

- 认知倾向； 

- 表达风格； 

- 关系模式。 

---

九型模型：

关注：

- 核心动机； 

- 注意力方向； 

- 防御模式； 

- 陪伴需求。 

---

两者关系：

```Plain Text
人格特征

↓

九型参数解释

↓

AI互动策略
```

---

# 输入数据结构（参考）

初始人格系统输入不限于单一来源。

可能包括：

- 人格测评结果； 

- 行为分析结果； 

- 用户长期互动数据； 

- 其他人格模型输出。 

---

## 4\.1 基础身份信息

示例：

```Plain Text
basic_profile:

  age:

  gender:

  background:
```

说明：

该部分用于辅助场景理解。

不直接决定九型参数。

---

# 4\.2 人格标签信息

示例：

```Plain Text
personality_labels:

  mbti:

  other_personality_types:
```

说明：

人格标签属于辅助信息。

不直接映射为九型类型。

---

# 4\.3 行为参数信息

推荐结构：

```Plain Text
behavior_features:

    assertiveness:

    creativity:

    depth_of_thought:

  action_pattern:

    structure_pref:

    discipline:

    adaptability:

    persistence:


  self_pattern:

    confidence:

    optimism:


  relationship_pattern:

    romantic_orientation:
```

# 输入参数到九型模型的转换原则

## 5\.1 不采用一对一映射

禁止：

```Plain Text
MBTI类型
↓
九型类型
```

或者：

```Plain Text
单一行为参数
↓
九型类型
```

---

原因：

人格类型是多维组合结果。

---

# 5\.2 采用多参数综合映射

转换逻辑：

```Plain Text
多个行为特征

↓

人格倾向信号

↓

九型参数层
```

---

示例：

输入：

```Plain Text
assertiveness:
  0.99

confidence:
  0.91

persistence:
  0.82
```

转换为：

```Plain Text
personality_signal:

  autonomy_orientation:
    high

  influence_orientation:
    high

  action_drive:
    high
```

再进入九型参数模型。

---

# 参数映射方向参考

以下映射用于技术搭建参考。

不是固定规则。

---

# 6\.1 Motivation Layer映射

目标：

推断用户可能的核心动力方向。

---

输入参考：

- confidence； 

- assertiveness； 

- persistence； 

- achievement orientation。 

---

输出参考：

```Plain Text
motivation_signal:

  autonomy_need:

  achievement_need:

  security_need:

  connection_need:

  identity_need:
```

---

对应九型参数：

```Plain Text
personality_signal

↓

core_drive

core_need

core_fear
```

---

# 6\.2 Attention Layer映射

目标：

理解用户注意力偏好。

---

输入参考：

- openness； 

- creativity； 

- depth\_of\_thought； 

- adaptability。 

---

输出：

```Plain Text
attention_signal:

  novelty_orientation:

  stability_orientation:

  abstract_orientation:

  detail_orientation:

  social_orientation:
```

---

对应：

```Plain Text
attention_signal

↓

attention_focus

information_processing

decision_style
```

---

# 6\.3 Expression Layer映射

目标：

理解用户外显互动方式。

---

输入参考：

- extroversion； 

- social\_warmth； 

- thinking\_ratio； 

- empathy。 

---

输出：

```Plain Text
expression_signal:

  communication_directness:

  emotional_expression:

  logic_orientation:

  warmth_level:
```

---

对应：

```Plain Text
expression_signal

↓

persona

emotion_style

relationship_style
```

---

# 6\.4 State Layer映射

目标：

理解压力和稳定状态。

---

输入参考：

- confidence； 

- optimism； 

- adaptability； 

- persistence。 

---

输出：

```Plain Text
state_signal:

  resilience:

  pressure_response:

  recovery_style:
```

---

对应：

```Plain Text
state_signal

↓

secure_state

stress_state

defense_pattern
```

# 与九型底座边界说明

## 初始人格信息层负责：

- 生成用户特征； 

- 提供人格信号。 

---

## 转换接口层负责：

- 字段转换； 

- 参数归一； 

- 信息结构化。 

---

## 九型互动模型负责：

- 人格参数解释； 

- 互动策略生成。 

---

# V1\.0实现建议

当前版本建议：

采用：

> 规则映射 \+ 参数权重调整
> 
> 

方式。

不建议：

- 建立复杂黑盒模型； 

- 固化单一人格理论映射； 

- 创建大量人工类型模板。 

---

原因：

未来可能接入：

- 不同人格测评体系； 

- 用户行为数据； 

- 长期对话数据。 

需要保持接口开放。
